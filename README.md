# Mehar Graphics — Service Web Application

A modern, responsive service web application developed for **Mehar Graphics**, a commercial printing and branding business.

The application provides customers with an online platform to explore the company's services, view business information, discover previous work, and get in touch for customized printing and branding requirements.

## 🚀 Project Overview

The goal of this project was to build a professional digital presence for a real-world business while providing a simple and user-friendly experience for customers.

The website focuses on:

* 🖥️ Modern and responsive user interface
* 📱 Mobile-friendly design
* 🏢 Business and service presentation
* 🎨 Printing and branding service showcase
* 🖼️ Portfolio/project presentation
* 📩 Customer-focused contact and inquiry flow
* ⚡ Fast and intuitive navigation

## ✨ Key Features

### 🏠 Modern Homepage

A clean landing page that introduces Mehar Graphics and highlights its primary services and value proposition.

### 🛠️ Service Showcase

Dedicated sections for presenting the company's printing, branding, and customized service offerings.

### 🖼️ Portfolio

A structured presentation of previous work and projects to help customers understand the company's capabilities.

### 📞 Contact & Inquiry

Customer-focused sections that make it easy for visitors to connect with the business and request services.

### 📱 Responsive Design

The application is designed to provide a consistent experience across:

* Desktop
* Laptop
* Tablet
* Mobile devices
